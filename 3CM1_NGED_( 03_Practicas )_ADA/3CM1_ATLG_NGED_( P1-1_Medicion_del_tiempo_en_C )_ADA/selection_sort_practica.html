Qué está midiendo la práctica

Los puntos conceptuales que debes explicar.

1. Entrada del peor caso

setWorstCase() genera n, n−1, ..., 1. El arreglo está completamente invertido antes de ordenar.

2. Medición aislada

La marca inicial se toma justo antes de selectionSort() y la final justo después. La construcción del arreglo no se incluye en el tiempo.

3. performance.now()

Devuelve una marca de tiempo de alta resolución en milisegundos. El tiempo experimental se obtiene con fin - ini.

4. Crecimiento cuadrático

Selection Sort realiza:

n(n−1) / 2 comparaciones.

  • 100 elementos → 4,950 comparaciones.
  • 100,000 elementos → 4,999,950,000.
  • 1,000,000 elementos → 499,999,500,000.
